# GOOC Dump

A decompilation of all GOOL scripts from the PAL versions of Crash Bandicoot 2 and Crash Bandicoot 3, translated into GOOC.

All scripts are supplied as editable source and can be recompiled into GOOL using my fork of ManDude's GOOC compiler. A precompiled binary is included in this repository, with source code available [here](https://github.com/Candyqwerl/gooc.git). Each script's header contains its corresponding compile command for convenience, so you should preserve the original directory structure.

For more information about the GOOC language, see ManDude's [GOOC](https://github.com/ManDude/gooc) repository.
